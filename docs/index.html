ForeTrack4D

Forecast vs. reality — 3D object motion forecasting from a single image

Given one frame of a hand-object interaction and a set of query points on the object, a conditional diffusion model predicts the object's future 3D motion — not pixels, not a video, just 3D point tracks. See the full repo for details.

In-domain, the model works

On held-out data from datasets it trained on, both learned models beat the "predict no motion" static baseline by a wide margin. Error at the final predicted frame drops from 33.4cm to 14.5cm:

DexYCB test (n=1200, never touched during training)ADE (cm)final-frame error (cm)
static baseline (no motion)12.4633.36
direct-regression baseline7.8514.50
diffusion, best of 5 samples*7.4315.91
diffusion, single sample10.4520.19

*"best of 5" picks the closest sample using the ground truth, which the deterministic baselines do not get. Judged on a single sample — what deployment actually delivers — the plain regressor is the more accurate model. The diffusion model's measurable advantage is the shape of its output distribution: the spread of motions it predicts across the dataset is 12.97cm against a ground-truth spread of 12.15cm, so it reproduces how much objects really move rather than collapsing or scattering.

The open problem: zero-shot generalization

The examples above are all in- or near-domain. The real test — and the thing this project is still actively working on — is generalization to a dataset the model never trained on in any way: EgoExo4D (25 held-out clips, zero training data, zero pseudo-labels, ever). No EgoExo4D video is shown here or anywhere in this demo (licensing — see below), but the numbers are reported in full, including where the model currently loses:

ADE (cm, lower better)motion spread predicted vs real
static baseline (no motion)19.76—
direct-regression baseline23.41 (loses)—
diffusion forecaster23.83 (loses)0.97 vs 33.30 (collapsed)
diffusion + OOD confidence gate20.93 (still loses)—

Both learned models lose to the static "predict no motion" baseline on this genuinely unseen domain. The diffusion model's motion distribution collapses almost completely: it predicts a spread of 0.97cm where real motion spans 33.30cm, and all five samples for a given input are effectively identical. An inference-time confidence gate recovers part of the gap but does not close it. ForeHand4D's headline result is that imputed labels improve zero-shot performance for hands; at this project's pseudo-label scale (213 accepted clips) that result does not reproduce for objects. This split is also small (n=25), so it is directional rather than conclusive.
